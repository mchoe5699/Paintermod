# QWERTY's Painter (Forge 1.20.1)

PC의 사진을 아무 블록 면에나 붙이는 모드입니다. 원래 블록은 그대로 두고 그 위에 사진을 덧그립니다.

## 사용법

**페인트 붓** (막대기 2개 + 양털 대각선 조합, 또는 크리에이티브 '도구 및 유틸리티' 탭)

1. 붓으로 블록을 우클릭 → **첫 지점** (클릭한 면이 사진을 붙일 면이 됨)
2. 다른 블록을 우클릭 → **마지막 지점** (다시 누르면 마지막 지점만 바뀜)
3. **첫 지점을 다시 우클릭** → 그 영역이 담긴 **사진 캔버스** 아이템 생성
   - 첫 지점을 두 번 연속 누르면 블록 1칸짜리 캔버스
   - 웅크리고 허공 우클릭: 선택 취소

**사진 캔버스**를 우클릭하면 사진 채우기 창이 열립니다.

- 사진: `PC에서 사진 선택…`, 경로 입력 후 `불러오기`, 또는 파일을 창에 끌어놓기 (png/jpg/bmp/gif)
- 회전 ↺ ↻ (90°씩), 좌우·상하 반전, 발광(어두운 곳에서도 밝게)
- 면: 붙일 면을 6방향 중에서 바꿀 수 있음
- 크기: 영역에 늘리기 / 비율 유지 맞추기 / 비율 유지 꽉 채우기 / 직접 지정(가로·세로·X·Y, 블록 단위, 소수 가능)
- 오른쪽 미리보기에 영역 격자와 사진 위치가 보입니다. `적용`, `영역 지우기`

**블록 하나씩 편집**: 붓을 들고 웅크린 채 블록 우클릭 → 그 블록의 6면을 각각 편집

- 면 선택(북·남·동·서·위·아래, ✔ = 사진 있음)
- 이 면에 새 사진, 회전, 반전, 확대/축소, 보이는 부분 이동(◀▶▲▼), 발광
- 복사 / 붙여넣기, 6면 모두 적용, 이 면 지우기

블록을 부수거나 폭발로 사라지면 그 블록의 사진도 지워집니다.

## 저장 위치

- 사진: `월드폴더/qwertys_painter_images/<해시>.png` (같은 사진은 한 번만 저장)
- 칠한 면 정보: `월드폴더/data/qwertys_painter_paint.dat` (차원별)
- 멀티플레이: 사진은 서버에 올라가고 다른 플레이어에게 자동으로 내려받아집니다.

## 설정

- 서버(`serverconfig/qwertys_painter-server.toml`): 캔버스 한 변 최대(128), 최대 블록 수(16384), 사진 최대 용량(8192KB)
- 클라이언트(`config/qwertys_painter-client.toml`): 업로드 전 사진 최대 픽셀(1024), 그리기 거리(128)

## 빌드

GitHub에 올리면 Actions가 자동으로 빌드합니다 → Actions 탭의 `qwertys_painter-jar` 아티팩트.
직접 빌드: `./gradlew build` (JDK 17) → `build/libs/qwertys_painter-1.0.0.jar`
